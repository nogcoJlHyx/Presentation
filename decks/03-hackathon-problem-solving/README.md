# 🏆 Хакатон IThub & SILA Union: Оптимизация цепочки поставок

> Защита решения кейса по моделированию бизнес-процессов, аналитике срывов сроков и разработке дерева целей для крупного строительного проекта.

---

## 📌 Проблема бизнеса (AS-IS)
Критический срыв сроков строительства социально значимого объекта (школы):
- В срок приходит только **каждая третья поставка (31% — 5 из 16)**.
- Суммарная задержка: **107 дней**, объем поставок с риском: **29,4 млн руб.**
- **Корневые причины (Root Cause):** хаотичный тайм-менеджмент, отсутствие резервирования по критическому пути, ошибки в заявках и отсутствие скоринга поставщиков.

---

## 💡 Предложенное решение (TO-BE)
Команда разработала комплексную систему стабилизации поставок в среде **SILA Union**:
- 🎯 **Дерево целей:** достижение **90% поставок в срок** к 01.03.2027 и ввод объекта во 2 квартале 2027 г.
- 🤖 **ИИ-методология подготовки документации:** снижение ошибок в спецификациях до 0.
- 📊 **Тайм-менеджмент и CPM:** управление критическим путем поставок (лимит задержки $\le 2$ дней).
- 🔍 **Регламент скоринга и проверки контрагентов:** лимит срывов $\le 1$.
